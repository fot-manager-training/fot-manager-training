# Domain Lisa: photos and documents

This pinned package updates fot-manager-training.ru with up to 3 attachments per message, 10 MB each. JPG/PNG/WebP and scanned PDFs use local Russian/English OCR; PDF, DOCX, XLSX, PPTX, TXT/CSV provide extracted text. Users can review and correct that text before sending. Original files are temporary; the existing cloud agent receives text as untrusted client data and retains its Sber comparison scope. Uploaded text remains in browser chat history, not the public bank catalog.

The root installer installs required Debian/Ubuntu OCR/document packages if missing, preserves the existing statistics core and database/key, adds one exact Nginx upload location, backs up configuration/data, and supports rollback. GitHub Pages main is unchanged. Text PDFs process up to 20 pages, scans up to 6, PowerPoint up to 20 slides; per-file extracted text is limited to 18,000 characters with warnings. Formulas are not executed. No model key is included.
