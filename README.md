# Lisa: Sber salary-project comparison

Pinned domain frontend update for fot-manager-training.ru. Lisa represents Sber and compares competitors' salary-project terms with our standard terms and separately proposed client changes. It uses available dated bank snapshots, produces concise comparisons and objection scripts, and refuses unrelated requests on the cloud backend before answering. Model secrets remain in the cloud. The VPS installer downloads all frontend files from this pinned GitHub snapshot, preserves local statistics and supports rollback. GitHub Pages main remains unchanged.
